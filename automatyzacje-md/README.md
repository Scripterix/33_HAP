# Pomysły ze snów

Tutaj Writer zapisuje interpretacje inspirowane Snami Iskry. Są one prezentowane na stronie jako publiczny strumień HAP. Publikacja interpretacji nie oznacza decyzji o realizacji: wybór do ewaluacji, eksperymentu lub projektu pozostaje osobnym etapem zależnym od człowieka.

## Sposób generowania pomysłów 

```bash
npm run writer -- sen-o-trzecim-krzesle.md
```
